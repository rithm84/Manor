The second-derivative test hinges on the sign of the Hessian determinant at each critical point: positive with fxx > 0 is a local minimum, positive with fxx < 0 a local maximum, negative a saddle. Zero tells you nothing — fall back to the boundary walk or a Lagrange setup. The practice exam leans hard on classifying saddles fast, so the numeric check below is worth keeping loaded.
PYTHON copy
def hessian_det(f, x, y, h): # second partials via central differences fxx = (f(x+h, y) - 2*f(x, y) + f(x-h, y)) / h**2 fyy = (f(x, y+h) - 2*f(x, y) + f(x, y-h)) / h**2 fxy = (f(x+h, y+h) - f(x+h, y-h) - f(x-h, y+h) + f(x-h, y-h)) / (4*h**2) return fxx*fyy - fxy**2
