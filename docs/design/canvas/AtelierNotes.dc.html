Calc III — Ch 14 review
The whole chapter is one move done four ways: linearize a surface, then read everything off the linearization. Partial derivatives give the slopes, the gradient stacks them into the direction of steepest ascent, and the tangent plane is just the linear approximation wearing a hat. For the exam: Lagrange multipliers are where the points go — set ∇f = λ∇g, then check the boundary by hand.
gradient_check.py python
import numpy as np   def grad(f, p, h):     # central difference, one axis at a time     return np.array([(f(p + h*e) - f(p - h*e)) / (2*h)                  for e in np.eye(len(p))])   f = lambda v: v[0]**2 * np.sin(v[1]) grad(f, np.array([1.0, np.pi/2]), 1e-5) # [2. 0.]

Lagrange — exam recipe
1.Write ∇f = λ∇g and the constraint g = 0 as one system.
2.Solve for candidates — watch the λ = 0 and division-by-zero branches.
3.Evaluate f at every candidate and at boundary corners; the extremes are just the biggest and smallest numbers on the list.
