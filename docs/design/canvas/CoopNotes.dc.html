Calc III — Ch 14 review
The gradient ∇f points in the direction of steepest ascent, and its magnitude is the slope in that direction. For the exam: the directional derivative Duf = ∇f · u only works when u is a unit vector — normalize first, every time. Level curves are perpendicular to ∇f, which is the fastest sanity check when a sketch looks wrong.
# numeric gradient — quick check for 14.6 answers def grad(f, p, h): return [(f(p + h*e) - f(p - h*e)) / (2*h) for e in basis(len(p))]
